# ПАСС

Демонстрационная версия сайта сервиса подбора школы и кадрового сопровождения для индустрии гостеприимства в Москве.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run lint
npm run build
```

Данные партнёров, кейсов, статистики, стоимости, документов и Telegram-интеграция в текущей версии являются заглушками и должны быть заменены до публикации.
